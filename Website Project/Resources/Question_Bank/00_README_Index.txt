WHAT THIS IS
------------
A complete, organized question bank covering the whole first-term syllabus (5 units + the novel
"The Lost World" Chapters 1-5), built question-by-question from the three external books
(GEM, El-Moaser, Giants) and aligned with the official Ministry Student Book (SB), which was
used as the syllabus reference.

Every question states which book it was taken from (GEM / El-Moaser / Giants / SB).
When the same question appears in several books, the sources are merged into one entry with a
combined label (e.g. "GEM + El-Moaser + Giants"). No question idea is repeated more than twice
in the whole bank, to prevent duplication. Each question file has a matching MODEL ANSWERS
file with identical numbering.

Total: 6,057 questions, all with model answers:
- Units 1-5: 5,219 questions
- The Lost World (Chapters 1-5): 273 questions
- General Skills (reading / writing / translation / dialog / pre-assessment): 565 questions

THE FIVE UNITS (SB syllabus)
----------------------------
Unit 1 — Living Well in a Complex World (Well-being)

STRUCTURE OF EACH UNIT FILE (question order as required)
---------------------------------------------------------
Section 1 — Vocabulary (V): MCQs, scenario-based vocabulary-in-context, definitions,
           synonyms, antonyms, collocations, word formation, gap-fills
Section 2 — Grammar (G): MCQs, rewrites, error correction, text completion — the unit's
           grammar points (relative clauses, participial phrases, conditionals, gerunds &
           infinitives, prepositional phrases, concession, fronting, present perfect,
           cause & effect connectors, modals, adverbials, ...)
Section 3 — Reading & Listening (R / L): all comprehension questions on the unit's passages
           and recordings (direct, inference, analysis, evaluation, T/F with justification)
Section 4 — Writing Skills, JRE & Critical Thinking (W / J / C): writing tasks (paragraphs,
           essays, emails, reports, leaflets, slogans), JRE = Justify-Reason-Evidence
           questions, and critical-thinking / discussion questions
Section 5 — Translation (T): English <-> Arabic items from the unit sections

The novel file is organized chapter by chapter (1-5): summary, comprehension, analysis,
critical, JRE and quote questions.

ANSWER FILES
------------
Each *_Answers.txt file mirrors the numbering of its questions file exactly:
- MCQs: correct letter + option + one-line reason
- Open questions: full model answers
- JRE questions: Justification -> Reason -> Evidence structure (several use GEM's official
  model answers from the book itself)
- Writing tasks: complete model paragraphs/essays (100-150 words)
- Translation: correct Arabic/English rendering
Where a question asks for a personal opinion, the model answer shows one strong response —
your own justified view is equally valid.

HOW TO STUDY WITH THIS BANK
---------------------------
1. Follow lesson order inside each unit file (Lesson X.1 -> X.4), as the books do.
2. Attempt every question BEFORE opening the answers file.
3. For JRE questions always answer in three steps: state your position (Justification),
   give your reasons (Reason), support with text/world evidence (Evidence).
4. The writing-section MCQs teach the exam logic (paragraph structure, audience, tone,
   persuasive techniques, hedging/neutral language) — do not skip them.
5. For the novel, read each chapter summary + questions, then check the model answers.

NOTE ON OCR
-----------
The source books were scanned (OCR), so a handful of heavily garbled items could not be
recovered; they were dropped rather than reproduced incorrectly. A few option texts keep
bracketed notes where the OCR was ambiguous. Everything else was cleaned into readable
English.
